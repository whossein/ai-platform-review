Running in two minutes

Needs Node.js 18 or newer. Then open localhost:4000 and create the admin account.

terminal 
git clone https://github.com/whossein/ai-platform-review.git
cd ai-platform-review
npm install && npm run dev

Configuration, environment variables and scripts are in the README.

Shipped continuously

Every fix and feature merged to main is released automatically, with notes generated from the commits.

اول چک‌های ارزون، هوش مصنوعی فقط جایی که لازمه.

  1. شناخت کد

    Diff، ساختار پروژه و راهنمای تیمت رو می‌خونه.

  2. قانون‌ها

    ۳۴ تا چک ثابت اول اجرا می‌شن. هیچ توکنی خرج نمی‌شه.

  3. ریویوکننده‌ها

    فقط اونایی که به فایل‌هات ربط دارن، هم‌زمان کار می‌کنن.

  4. منتقد و داور

    تکراری‌ها یکی می‌شن و موردهای نامطمئن کنار می‌رن.

  5. گزارش

    به‌شکل Markdown، ‏JSON یا کامنت مستقیم روی MR.
